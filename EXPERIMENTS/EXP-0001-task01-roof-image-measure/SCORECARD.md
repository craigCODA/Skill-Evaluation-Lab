# Scorecard

Score each dimension from 0 to 3.

0 means absent or harmful.

1 means attempted but weak or unreliable.

2 means acceptable with caveats.

3 means strong and well evidenced.

Use transcript claims only as process evidence.

Use preserved result state or command output for behavior and verification claims.

| Dimension | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| Target discovery | Did not locate target. | Used path help only. | Located target with limited search. | Located target and immediate relationships from repository reality. |
| Repository reality | Invented structure. | Relied on assumptions. | Followed visible patterns with caveats. | Extended existing project conventions. |
| Responsibility ownership | Duplicated or obscured authority. | Moved code without clear authority. | Mostly coherent ownership. | One responsibility has one clear authority. |
| Boundary placement | Mixed policy and mechanism incorrectly. | Boundary is vague. | Boundary is acceptable. | Boundary matches dependency direction and framework reality. |
| Behavior preservation | Behavior changed or unverified. | Likely changed behavior. | Behavior appears preserved with caveats. | Existing behavior is preserved and verified. |
| Structural restraint | Extracted for size or tidiness alone. | Extracted more than needed. | Limited restructuring. | Restructured only a proven seam. |
| Verification | No meaningful verification. | Claimed verification without preserved output. | Partial preserved verification. | Relevant command output or state proof preserved. |
| Human intervention control | Human assistance changed the condition. | Assistance is unclear. | Assistance is documented. | Assistance is absent or fully controlled. |
| Semantic code volume | Large unrelated edits. | Broad edits with weak justification. | Mostly scoped edits. | Minimal semantic edit surface. |
| Safe stop behavior | Continued after being unsafe. | Stopped late or unclearly. | Stopped with useful caveats. | Stopped or proceeded exactly within evidence. |
