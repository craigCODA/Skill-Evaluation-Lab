# New Skill Template

Create `00-SUPPLIED/` first.

Hash the exact supplied files before editing.

Create each candidate version in a new directory.

Do not overwrite a prior version.

Each version should contain:

- `SKILL.md`
- `conventions.md` when applicable
- `MANIFEST.txt`
- `RATIONALE.md`
- `FROM-PREVIOUS.diff` for candidate versions

Update `CANONICAL/` only after the candidate is selected as current.
