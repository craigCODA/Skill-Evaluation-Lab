## 3. Line items, metal, trim — categorization

**Pattern:** Each option declares `billed: boolean` in `shared/options/types.ts` (`OptionMeta`). Billed options roll into `grandTotal` when included in the sum in `calculateEstimate.ts`.

| Category | Examples | Billed to customer? |
|----------|----------|---------------------|
| **Per-area install / labor+material** | `install` | Yes (in area subtotal) |
| **Trim — drip edge** | `dripEdge` (eave/rake LF × style $/ft) | Yes (in area total) |
| **Underlayment** | `underlayment` | Yes |
| **Ice & water (closed valley LF on plane)** | `iceWater` uses `area.iceWaterValleyLf` + `iceWaterRates` key `"valley"` | Yes when coverage option covers valleys |
| **Flashing — step** | `stepFlashing` → `flashingRates` | Yes |
| **Open valley metal (job-level)** | `roofing.valleys.style` + `openLf` → `valleyMetalRates` `"open-valley"` | **No** (`valleyMetalOption.billed: false`) |
| **Accessories (vents, pipe boots, …)** | `accessories` → `accessoryRates`, count × unit | Yes |
| **Materials take-off** | `materialsCounts` | **No** (order list / roof order form) |
| **Permit & extras** | `Job.permit`, `Job.extras` | Yes (in grand total) |

**Two different “valley” concepts:**
1. **Job-level open/closed valley metal:** `RoofingScope.valleys` (`ValleySelection`: `style`, `openLf`, `closedLf`) — priced in `valleyMetal.ts`, shown in `RoofingScopeForm.vue`, **not billed**.
2. **Per-plane I&W valley LF:** `RoofArea.iceWaterValleyLf` — billed via `iceWater.ts` when I&W coverage includes valleys (`RoofPlaneEdgesSection.vue`).
